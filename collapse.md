The set of contact events as described in [[theory core]] represents a static environment. To add detail to our theory, let's consider at least several static environments, which could be interpreted as instantaneous states of an evolving environment, and transformations between them such that
- $\tau:(K,Y)\mapsto (L,X)=(\{$a subset of contact events$\},\{$a set of vertices as their boundary$\})\mapsto$ an equivalent type pair in the transformed environment
- $\exists\tau(K,Y)\Rightarrow\exists\tau(\kappa,\chi\cup\upsilon), \kappa\nsubseteq L,\chi\subseteq X,\upsilon\cap X=\emptyset$
Informally this represents that some pairs of endpoints that can get into contact evolve so that at the next observation a new set of endpoints can be selected (from the evolved set of endpoints) that can get into contact and evolve according to the applied transformation, with contacts not contained in the image of the prior selection. This means for the network to evolve in the following stages
1. a set of contact events and their 2 sets of endpoints are identified, both of the latter can be considered (in case disjoint unions of the the contact events select disjoint unions of endpoint sets, then respective sets of) _interfaces_ in an interaction as understood in another, superimposed theory
2. on each interface the interaction takes effect (transmission of information, force etc.)
3. the interface is transformed: the superimposed theory estimates its transient behavior (cf. [[information#non-static causal structure]]) and the network of endpoints and contacts is restructured to reflect the updated state at a later instant
4. the contacts between the updated interfaces and other ones excluded from the interaction are updated so that the excluded ones admit the definition of the same interfaces (in the superimposed theory) towards the updated ones as before the interaction, i. e. interactions leave the non-participating interfaces invariant

The network with contact events as edges does _not by itself_ represent an ongoing interaction, or a snapshot in the history of the environment, but _a pair_ of networks can be interpreted as an "episode" of interaction dynamics. In a single network, each contact event signifies a recognized characterization of an interaction between interfaces in a superimposed theory, and each endpoint a characteristic of an instance of the corresponding interface.

Put differently, the network picture is an attempt at formalizing 2 pieces of insight:
- the organizing primitive of dynamical models is a specific moment of an interaction to quantify, and that is supported by the distinction of 2 entities and a prescribed way of quantifying their interaction
- to be able to simultaneously reason about multiple possible (models of) interactions without fixing the type of a participating entity to be the same for all of them, the recognized types must be composed of (possibly atomic) signatures, a subset of which together determines the entity's behavior in interaction

A network thus contains a set of potential interactions as well as potential materializations of an object as recognized via its interface. It describes the environment as a complex system lending itself to many ways of organizing into constituents, and selecting a potential interaction points to one way (which may exclude other organizations that are inconsistent with it).

The network picture aims at formalizing a worldview. In colloquial terms, we could explain it as follows: anything we care about is accessed through one or a series of transitions from one idealized, unobserved state to another. By limiting the set of relevant transitions we filter the world for such objects that allow for those transitions to happen. E. g. visible objects have light-emitting or reflecting surfaces, invisible ones have gravitating mass, imaginary objects manifest as repeated interpersonal behavioral patterns, signifiers obey grammar etc.
### what to collapse
We make one further assumption explicit: $\tau$ accurately describes the network reconfiguration following an interaction if and only if there is a bijection between the interfaces represented in the network $\{Y_i:Y=\sqcup_iY_i\}$ and their representation in a specific instance of interaction in the superimposed theory. That is to say, each well-understood interaction that instantaneously defines an interface for 2 objects proceeds so that between 2 instants of the interaction neither object interacts via the same interface with a 3rd object, according to the network model. Or, again differently put, a single pair of endpoints $x_{ij}$ and their corresponding operator $\phi_i$ is in a one-to-one correspondence with the same structures in $(K,Y_i)$ in all evaluations, "$Y_i$ could be defined as a single contact event for all intents and purposes". Going forward, we shall say that the interface $Y_i$ can be collapsed into a contact event, which is not necessarily by what we define a transformation $\tau$ as seen above, but can be the mapping of another $\check\tau$.
### when to collapse
A network supporting multiple superimposed theories that can be considered as different coarse-grainings describing the same substrate-level phenomenon admits $\{\check\tau_i$ collapsing transformations$\}$. Informally, coarse-grainings exist because they describe phenomena in much lower complexity at the expense of losing little information compared to the fine-graining. If we can consider such a tradeoff a(n at least informal) gauge of efficiency then for $\check\tau_i$ another collapse $\epsilon_i$ can estimate the efficiency $e(\phi_{ij})$ for $(x_{ij2}\phi_{ij}x_{ij1})$ in $\check\tau_i$, and an estimate comparison can be made for $\braket{\epsilon_i}=\braket{e(\phi_{ij})}_{p(j)}(i\in\{1,2\},p$ is a measure to express a preference over collapsed contacts $j)$. We could argue that $\braket{\epsilon_i}$ thus gives an (at least informal) expected priority-weighted efficiency, or return-over-cost, or utility of $\check\tau_i$. Without going into deductions about the directive of $\epsilon_i$ in selecting coarse-grained theories we can at least claim that under resource scarcity those $\check\tau_i$ will be more frequently observed which score higher on $\braket{\epsilon_i}$. We shall precise this claim further [[later]].
