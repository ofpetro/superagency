On a very minimal, surface-level reading, this is a review of the core arguments in the discourse on safe superintelligent AI with a – hopefully – clear conclusion.

Read more thoroughly, it should give fairly clear directions to design a safe application of AI scaled potentially to superintelligence.

Beyond these design directions, it should help figure out finer details so that it becomes clear in the process how to follow the directions in any subsequent safe AI application.

Ideally, the text itself is also an example both of a safe-by-design application (on the object-level) and the planning thereof (on the meta-level).

Meanwhile, it should explain that the interactive format (following the [interaction guide](2)) serves to create the product as you engage with it, so you are already participating in constructing the ever-safe AI application.

Read this if you have [skepticism in safe AI]() being ever achieved, and therefore need convincing.
