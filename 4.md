* identify key features of the vision of the (future) ecosystem i have in mind // as opposed to:  
  * distributed architecture of superintelligent AI // compact or monolithic solution  
  * interfaces to more capable models stand up to higher safety standards // prioritizing easy access  
  * it is possible to engage any agent in negotiation in which their “belief state” is probed faithfully // freedom to refuse cooperation in entering into and maintaining negotiation[^1]; possibly in this form:
	  * helpful participation in negotiation as well as differences on subjectively held values have explicit economic value // credit can be extorted in deceitful ways in the form of currency (especially cash)

[^1]: This might be impractical, keep that in mind.
